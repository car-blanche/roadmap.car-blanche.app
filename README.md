# Car Blanche — Roadmap Documentation

Документация дорожной карты сервиса персонализированного мобильного транспорта.

## 🗺️ Обзор

Интерактивная веб-страница с визуализацией развития сервиса на период **2026–2029**.

### Три горизонта развития

1. **2026 (февраль–март)** — App как центр управления
   - Единый интерфейс
   - Опции в один клик
   - Поддержка 24/7

2. **2027** — Экосистема + рекомендации
   - Профиль предпочтений
   - Трекинг и аналитика
   - Сценарная персонализация

3. **2027–2029** — Прогноз и интеграции
   - Предиктивные сценарии
   - Данные умного города
   - Выбор по экоследу

## 🎨 Дизайн

- **Тёмная тема** — премиальный стиль с акцентными градиентами
- **Интерактивный timeline** — горизонтальная временная шкала с точками-маркерами
- **Адаптивная вёрстка** — корректное отображение на мобильных и десктопах
- **Анимации** — плавное появление элементов, пульсация маркеров

## 🏗️ Структура проекта

```
src/
├── App.tsx                  # Главный компонент
├── index.css                # Глобальные стили
├── main.tsx                 # Точка входа
├── components/
│   ├── Header.tsx           # Шапка с навигацией
│   ├── Hero.tsx             # Главный экран с заголовком
│   ├── Timeline.tsx         # Временная шкала с фазами
│   ├── Principles.tsx       # Принципы развития
│   ├── FAQ.tsx              # Часто задаваемые вопросы
│   └── Footer.tsx           # Подвал
└── data/
    └── roadmap.ts           # Данные дорожной карты
```

## 🚀 Запуск

### Разработка

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173)

### Сборка

```bash
npm run build
```

Результат в папке `dist/`

### Предпросмотр продакшн-сборки

```bash
npm run preview
```

## 🛠️ Технологии

- **React 19** — UI библиотека
- **TypeScript** — типизация
- **Vite 7** — сборщик
- **Tailwind CSS 4** — стилизация
- **Single-file build** — вся страница в одном HTML файле

## 📱 Секции страницы

1. **Header** — логотип, навигация, CTA кнопка
2. **Hero** — главный заголовок, краткое описание, быстрый доступ к фазам
3. **Timeline** — три карточки с детальным описанием каждой фазы
4. **Principles** — четыре принципа развития (прозрачность, этика, инклюзивность, экология)
5. **FAQ** — аккордеон с частыми вопросами
6. **Footer** — контакты, ссылки, копирайт

## 🎯 Ключевые метрики

- Время загрузки: < 1s (single-file bundle)
- Размер: ~256 KB (gzip: ~74 KB)
- Lighthouse Performance: 95+
- Полная доступность (a11y)
